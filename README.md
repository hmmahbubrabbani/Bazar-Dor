# Project Name: 🛒 BazarDor (বাজার দর)

# Short Description: A modern and dynamic price-tracking web application that allows users to view and compare current market prices of essential commodities at a glance.

---

## 🛠️ Technologies Used

* **Frontend & Framework:** Next.js 16.4.0 
* **Styling:** Tailwind CSS, HeroUI Components, Daisyui components 
* **Authentication:** BetterAuth
* **Notifications:** React Hot Toast
* **Language:** TypeScript / React
* **Display:** Marquee Text

---

## 🚀 Key Features

* **1. Real-Time Price Tracking & Comparison:** Easily compare current prices of essential daily goods across different markets.
* **2. Secure User Authentication (BetterAuth):** Secure sign-in and sign-up functionality via email/password and social login options (Google & GitHub).
* **3. Protected Routes:** Secure profile and product details pages protected via proxy.ts file, preventing unauthenticated access.
* **4. Global Notification System:** Instant and attractive toast notifications for user actions (successful login, registration, or errors) powered by `react-hot-toast`.
* **5. Responsive & Modern UI (HeroUI & Tailwind CSS):** A clean, modern, and fully optimized user interface for both mobile and desktop devices.
* **   And running ticker bar right below the header that displays real-time price fluctuations of essential commodities and urgent market  updates to users at a glance using marquee text.
